# DoiTung E-Ticket Prototype + ESP32 LCD

เว็บต้นแบบขายบัตรเข้าชมดอยตุงแบบอัตโนมัติ พร้อม:
- หน้าเว็บจองบัตรสไตล์ใช้งานจริง
- ชำระเงินจำลอง
- ออกบัตร QR Code
- ตรวจบัตรโดยเจ้าหน้าที่
- ป้องกันการใช้บัตรซ้ำ
- ส่งข้อมูลวันและเวลาซื้อ + วันที่เข้าชม + สถานะบัตร ไปแสดงบนจอ LCD ของ ESP32

## ฟีเจอร์เด่นในเวอร์ชันนี้
1. **QR Code มีข้อมูลของบัตร**
   - token ของตั๋ว
   - วันและเวลาซื้อ
   - วันที่เข้าชม
   > ตอนสแกน ระบบจะตรวจฐานข้อมูลอีกครั้งเสมอ เพื่อดูสถานะจริงว่าใช้แล้วหรือยัง

2. **หน้าตั๋วสวยขึ้น**
   - ใช้พื้นหลังภาพเวกเตอร์ของสถานที่ท่องเที่ยว
   - มีรายละเอียดวันที่ซื้อ เวลาซื้อ วันที่เข้าชม และสถานะบัตร

3. **เชื่อม ESP32 ผ่าน USB**
   - หน้า `/staff` มีปุ่ม “เชื่อมต่อ ESP32 ผ่าน USB”
   - เมื่อสแกนบัตร ระบบจะส่งข้อมูลไป LCD แบบอัตโนมัติ

4. **สถานะตั๋ว**
   - valid = ผ่านและถูกบันทึกว่าใช้งานแล้ว
   - used = ตั๋วถูกใช้งานแล้ว
   - wrong_date = ยังไม่ถึง/เลยวันเข้าชม
   - invalid = ข้อมูลตั๋วไม่ถูกต้อง

## วิธีเริ่มใช้งาน
### 1) ติดตั้ง Node.js
ใช้ **Node.js 22.13 ขึ้นไป**

### 2) เปิดโปรเจกต์
- ดับเบิลคลิก `start-windows.bat`
หรือ
- เปิด Terminal แล้วพิมพ์:
```bash
node server.js
```

### 3) เปิดเว็บ
เข้าเบราว์เซอร์ที่:
```text
http://localhost:3000
```

## วิธีทดลองระบบครบชุด

4. ล็อกอินเป็น `staff`

6. ต่อบอร์ด ESP32 เข้ากับคอมผ่าน USB
7. กดปุ่ม **เชื่อมต่อ ESP32 ผ่าน USB**
8. สแกน QR Code
9. ดูผลบนหน้าเว็บและหน้าจอ LCD

## การต่อสาย LCD กับ ESP32
ตัวอย่างสำหรับ **LCD 16x2 I2C**

| LCD I2C | ESP32 |
|---|---|
| GND | GND |
| VCC | 5V |
| SDA | GPIO 21 |
| SCL | GPIO 22 |

> ถ้าจอของคุณใช้ Address ไม่ใช่ `0x27` ให้แก้ในไฟล์ `esp32/doitung_esp32_lcd.ino`

## โฟลเดอร์สำคัญ
- `server.js` = ตัวเว็บเซิร์ฟเวอร์
- `src/pages.js` = หน้า HTML ทั้งระบบ
- `public/styles.css` = ตกแต่งหน้าเว็บ
- `public/app.js` = ฟังก์ชันฝั่งเบราว์เซอร์ + เชื่อม Web Serial ไป ESP32
- `esp32/doitung_esp32_lcd.ino` = โค้ดสำหรับอัปโหลดลงบอร์ด ESP32

## หมายเหตุ
- โปรเจกต์นี้เป็น **ต้นแบบ**
- ราคาบัตรเป็น **ข้อมูลจำลอง**
- ยังไม่ได้เชื่อม payment gateway จริง
- หากต้องการใช้จริง ควรเพิ่มระบบชำระเงินจริง, ส่งอีเมล, อัปโหลดหลักฐาน, บันทึก log เพิ่มเติม, และยืนยันสิทธิ์ผู้ใช้งานให้รัดกุมกว่าเดิม

## อัปเดตหน้าเว็บไซต์สำหรับผู้ใช้งาน (UI revision)
- ยกเลิกแถบสีเขียวข้อความด้านบนทุกหน้า
- ปรับเมนูนำทางบนคอมพิวเตอร์ให้มีขนาดใหญ่ขึ้น และเปลี่ยนเป็นเมนูมือถือเมื่อหน้าจอแคบ
- ปรับหัวเรื่องและข้อความในส่วนจองบัตรไม่ให้เบียดหรือตัดคำ
- ปรับเนื้อหาหน้าแรกให้เน้นข้อมูลการจองบัตรและสถานที่ท่องเที่ยว ไม่แสดงข้อความอธิบายการพัฒนาระบบหรืออุปกรณ์ภายใน
- รักษาระบบจองบัตร QR Code หน้าเจ้าหน้าที่ และระบบแสดงผล ESP32/LCD เดิม

**สำคัญ:** แม้ว่าหน้าเว็บไซต์จะออกแบบให้คล้ายเว็บใช้งานจริง แต่ระบบนี้ยังเป็นต้นแบบที่ชำระเงินจำลองเท่านั้น และไม่ใช่ช่องทางขายบัตรดอยตุงอย่างเป็นทางการ โปรดตรวจสอบและขออนุญาตก่อนนำไปให้บริการจริง
